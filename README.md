# Rede Social - Projeto de exemplo 2A 2026 (dw-2026-2a)

Projeto criado com HTML, CSS, PHP e Docker para apresentar alguns conceitos e funcionalidades para a turma do 2A de 2026.

Possui a documentação do banco. Contém relacionamentos `n:n`.
